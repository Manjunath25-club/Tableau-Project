# Netflix Content Analysis Dashboard

A Tableau dashboard project analyzing Netflix movies and TV shows to explore content trends, genres, and regional distribution.

## Project Overview

The dashboard uses Netflix content data to answer questions such as:

- How is Netflix content distributed between movies and TV shows?
- How has content volume changed over time?
- Which countries contribute the most content?
- What genres and content categories are prominent?

## Key Insights

- Movies represent the larger share of the Netflix catalog in the analyzed dataset.
- Netflix content volume increased significantly after 2015.
- The United States leads the analyzed dataset in content production.

## Tools Used

- Tableau
- Excel / CSV

## Project Files

- `Netflix_Dashboard.twbx` — Tableau packaged workbook
- `dashboard_screenshot.png` — Dashboard preview

## Analysis Approach

1. Load and inspect the Netflix dataset
2. Clean and prepare fields for visualization
3. Analyze content type, release year, country, and genre
4. Build interactive Tableau visualizations
5. Combine visuals into a dashboard
6. Extract trends and business-relevant insights
